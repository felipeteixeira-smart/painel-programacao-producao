# Painel de Programação de Produção - Espaço Smart

Aplicação Web moderna e responsiva para planejamento e acompanhamento da programação de fabricação de perfis e montantes da **Espaço Smart**.

## 🚀 Funcionalidades

- **Importação de Planilhas:** Suporte completo a arquivos CSV, XLSX e XLS com mapeamento flexível de colunas.
- **Gestão Semanal Independente:** Planejamento por semanas (ex: Semana 35, Semana 36) com navegação ágil entre períodos.
- **Catálogo Integrado:** Mapeamento automático de códigos para descrições completas dos perfis e montantes da fábrica.
- **Acompanhamento Plano x Real:** Apontamento diário (Segunda a Sábado) das quantidades previstas e produzidas.
- **Ordem de Produção (OP):** Campo editável para vincular o número da OP correspondente.
- **Status em Tempo Real:** Atualização automática de status (*Concluído*, *Parcial*, *Pendente*, *Não Produzido*).
- **Exportação:** Geração de relatórios em Excel (`.xlsx`) com dados e status consolidados.
- **Identidade Visual:** Interface corporativa personalizada nas cores da Espaço Smart (Laranja e Cinza).

## 🛠️ Tecnologias Utilizadas

- HTML5 / CSS3 / JavaScript (Vanilla)
- [SheetJS](https://sheetjs.com/) (leitura e geração de arquivos Excel/CSV)
- Font Awesome 6
- Google Fonts (Inter)

## 📦 Como Executar

Basta abrir o arquivo `index.html` em qualquer navegador moderno. Não requer servidor backend ou instalação adicional.
